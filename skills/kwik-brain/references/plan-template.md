# Plan template

Contents: structure, compression, weekend table, checkpoints, dates.

## Structure
- Title, one-line context (name, start date, end date).
- "How this plan is built": sources, time budget, assumptions.
- The weekday template table (see SKILL.md).
- Phases as tables: Day | Date | Core topic (45 min) | Practice slot (30 min). Number days continuously, including weekends.
- Weekend table: weekend number, dates, project goal. Saturday builds, Sunday finishes, documents and reviews.
- Spaced-revision rhythm: +1, +3, +7, +21 days for notes; Leitner for cards; Saturday weekly recap; monthly recap on the last weekend of each month.
- Checkpoints at phase ends (what the learner can now build or explain).
- Questions for the learner.

## Compression
If the source roadmap has more days than the learner has weekdays, compress topics the learner already knows (merge basics, keep one day for revision at the end of each phase). Keep order from the source.

## Final sprint
Reserve the last 10 days for revision and mocks: one phase per day, a weak-spot day, a full mock, a final cheat-sheet day. All revision there is quiz and flip-card style.

## Dates
Compute weekdays and weekends from the start date; label each row with the weekday and date. Day 1 may start midweek; make the first week partial.
