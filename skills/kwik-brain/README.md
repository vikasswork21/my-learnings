# Kwik-Brain skill (source)

The source of the `kwik-brain` Claude skill: a method for building study notes, plans and spaced-repetition revision for a visual learner.

- `SKILL.md`: the skill itself.
- `references/`: note anatomy, component API, memory techniques, plan template, delivery workflow.
- `assets/template-day.html`: starting page for a new day.
- `scripts/check_day.py`, `scripts/register_day.py`: verification and registration helpers.
- `assets/site/` is bundled in the packaged `.skill` file only. It mirrors the live site files in this repo: `/assets/style.css`, `app.js`, `visuals.js`, `favicon.svg`, `days.js`.
